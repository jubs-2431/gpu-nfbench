# ATC 2026 Submission Checklist

Prepared files:

- `paper/GPUTriage_ATC2026_Full_Blinded.pdf`
- `paper/GPUTriage_ATC2026_Extended_Abstract_Blinded.pdf`
- `paper/gpu_nfbench_atc_2026_full_blinded.tex`
- `paper/gpu_nfbench_atc_2026_extended_abstract_blinded.tex`
- `ATC_2026_GENERATIVE_AI_STATEMENT.txt`

Venue alignment:

- Format: ACM `acmart` with `sigplan,10pt`, page numbers enabled, copyright
  footnote removed, and references hyperlinked by the ACM template.
- Full paper: prepared as a short ATC submission; current compiled PDF is 5
  pages, within the 6-page short-paper limit excluding references and
  appendices.
- Extended abstract: prepared as a standalone 2-page abstract with title block;
  current compiled PDF is exactly 2 pages. References do not count toward the
  two-page limit.
- Review model: double-blind. Author name, institution, email, GitHub URL, and
  Zenodo DOI are removed from the paper body.
- Artifact: described as an anonymized artifact package for review. Public
  identity-bearing links should not be included in the blinded submission.
- GenAI: HotCRP requires an attestation. Use the text in
  `ATC_2026_GENERATIVE_AI_STATEMENT.txt`.

Important submission warning:

ATC does not allow simultaneous submission of the same work to multiple venues.
If the HPEC or BigData versions are currently under review, do not submit this
ATC version at the same time unless the work is clearly distinct and the venue
rules allow it.
